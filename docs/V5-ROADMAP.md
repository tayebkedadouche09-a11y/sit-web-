# NUMI 5.0 — Website Boutique

## ما في v5 الآن
- متجر شخصي لبيع مواقع جاهزة (كتالوج + تصنيفات + دفع)
- PostgreSQL / Supabase
- تسليم أوتوماتيكي بعد الدفع (GitHub private copy + Vercel) عند توفر المفاتيح و `sourceRepoUrl`
- واجهة أبسط للبيع (Hero قصير، بطاقات أوضح)
- بيانو هادئ + أجواء اختيارية (زر موسيقى)
- مساحة زبون أوضح: حالة التجهيز + زر **افتح نسختي**
- زر واتساب عائم (اختياري عبر `VITE_WHATSAPP_NUMBER`)
- إصلاحات Postgres (`returning` بدل `insertId` / `affectedRows`)

## أفكار مستقبلية (بعد الإطلاق الحي)
1. **لوحة تخصيص بسيطة** للزبون (ألوان/اسم/شعار) قبل أو بعد النشر
2. **باقات تعديلات** مدفوعة (تغيير نصوص، صفحات إضافية)
3. **دومين مخصص** مربوط تلقائياً على Vercel
4. **إشعارات واتساب/إيميل** عند READY
5. **تقييمات موثّقة** بعد الشراء فقط (موجود جزئياً)
6. **نسخ احتياطي مجدول** لقاعدة Supabase
7. **لوحة إحصائيات** أوضح للمالك (زيارات، تحويلات)
8. **قوالب عربية RTL كاملة** لكل منتج مباع
9. **وضع فاتورة PDF** بعد الدفع
10. **Multi-currency** ذكي (DZD افتراضي + EUR للخارج)
